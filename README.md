# C Day 83 - Sum of Divisible Numbers

This C program calculates the sum of numbers divisible by a given divisor.

## Example

Numbers: `9, 10, 12, 7, 15`

Divisor: `3`

Output:
```text
Sum of divisible numbers = 36
```

## Concepts Used

- Variables
- `for` loop
- `if` statement
- Modulus operator `%`
- Addition operator `+`
- `scanf()` and `printf()`

## How It Works

The program accepts numbers and a divisor from the user. It checks each number using the modulus operator. If the number is divisible by the divisor, it adds that number to the total sum.

## What I Learned

I learned how to use a loop and the modulus operator to calculate the sum of numbers divisible by a given number in C.
